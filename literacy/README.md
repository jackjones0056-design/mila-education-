# Kindergarten Literacy Mission

A 10-week, 50-session interactive literacy intervention tailored to the learner's STAR Early Literacy domain profile: phonological awareness 31, phonics/word recognition 31, vocabulary 38, print concepts 44, informational-text key ideas/details 56, and literature key ideas/details 80. The overall starting result was 648 scaled score / 31st percentile, Early Emergent / On Watch.

## Instructional allocation

The sequence deliberately devotes the largest share of practice to:

1. Phonological/phonemic awareness
2. Phonics, decoding, encoding, and word recognition
3. Vocabulary/oral language
4. Print concepts embedded in authentic reading routines
5. Informational knowledge/evidence work
6. Literary comprehension as a strength and transfer channel

The app does not teach picture guessing as a decoding strategy.

## Wit & Wisdom alignment

Wit & Wisdom is used as the knowledge/comprehension/vocabulary bridge. The Parent Dashboard has fields for the current class topic/book and vocabulary words. Those inputs are stored only on the local device and are used to generate discussion prompts. No copyrighted curriculum passages are bundled in this repository.

The Parent Dashboard also accepts the letters already taught by the school's foundational-skills program. When supplied, decoding/encoding activities restrict word generation to those letters whenever the local word bank permits it.

## Mastery rule

- 90%+ independent accuracy: secure / advance
- 80–89%: advance with spaced review
- 70–79%: repeat
- Below 70%: reduce difficulty and explicitly reteach

## Program structure

- 10 weeks
- 5 sessions per week
- 50 sessions total
- 6 short interactive rounds per session
- Spoken directions using browser speech synthesis
- Device-local progress and teacher-alignment settings
- Adaptive review rounds that target the weakest measured app domain
- PWA/offline caching after first successful HTTPS load

## Privacy

The public source does not include the student's full assessment report, surname, school, teacher, class/group, or test identifiers. It does include the non-identifying score profile because that profile drives the instructional design.
